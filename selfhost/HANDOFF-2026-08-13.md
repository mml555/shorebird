## Rules this session paid for

1. **Never `git add -A` in a shared worktree.** A `packages/shorebird_cli` change
   rode into a commit about a device gate. Stage explicit paths.
2. **An empty `git log <rev>..HEAD -- <path>` says nothing about uncommitted work.**
   Read the installed file.
3. **Never uninstall the fixture to clear updater state.** It resets iOS Local
   Network consent; the app then blocks on a modal before any code runs — no
   `patches/check`, no beacon — while `ios-deploy` still reports `success`.
4. **`flutter build ipa` defaults to the APP-STORE export method**, for which no
   profile exists here. The archive succeeds and only the export fails, so it reads
   as a signing-account problem. Pass a development + automatic
   `--export-options-plist`. This bit release 38 hours after release 37 exported
   fine.
5. **A release's installable bundle is not preserved by accident.** `shorebird patch
   ios` re-runs `flutter build ipa`; whether the release `.ipa` survives depends on
   whether that export succeeds. `preserve_release_evidence.sh` now keeps `App.ipa`
   (UUID-checked) and `launch_release_bytes.sh` prefers it.
6. **`RouteBReport` APPENDS.** Judge trace evidence by the INCREMENT per launch, not
   the absolute count. "2 records" was equally consistent with one attach per launch
   across two launches until the increment was measured.
7. **Look at the screen during a live run.** A harness can write every marker, attach
   in both engines, and display nothing — a scene manifest owning the window.
