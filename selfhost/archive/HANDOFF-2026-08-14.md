## Rules this session paid for

1. **A plan's specified design can be wrong, and only measurement says so.** H4
   specified a `Dart_LoadObfuscationMap` called from `bin/gen_snapshot.cc`. Under
   lldb the obfuscation map is seeded *inside* `Dart_CreateIsolateGroupFromKernel`
   (`InitializeRenamingMap ← Obfuscator::Obfuscator ← BootstrapFromKernelSingleProgram
   ← Object::Init ← CreateIsolate ← Dart_CreateIsolateGroupFromKernel ← bin::main`),
   before `Dart_Precompile`. An embedder-side call could only merge into a live,
   already-renaming map — it would have accepted the flag and renamed
   INCONSISTENTLY, which is worse than refusing it.
2. **A probe that feeds the same input twice cannot exercise state that only new
   input touches.** `g43`'s first version compiled the same kernel twice, so every
   identifier was already in the loaded map, `NewAtomicRename` was never called,
   and the cursor was never consulted. All three cursor modes reported 0
   collisions — including the two deliberately broken ones. Rewritten to compile a
   *release* then a *patch containing new identifiers*, the modes separate: 0 / 44
   / 81.
3. **`drift=0` does not mean correct.** Consistency passed in every cursor mode.
   Only the collision arm discriminates, and only the falsification arm proves the
   collision arm is alive.
4. **`publish_ios_overlay.sh` derives its hash from `Flutter.framework` alone.** A
   `gen_snapshot`-only change therefore derives an ALREADY-PUBLISHED hash. This is
   now refused in code (`31d5c66f`), not just documented.
5. **A refusal path is not trustworthy until it has been made to refuse.** The
   collision guard's own first draft aborted mid-refusal — `diff | grep | head |
   sed` exits 1 when there *are* differences, and under `set -e -o pipefail` that
   truncated the remediation message and made `FORCE=1` unreachable. Caught by
   testing all four paths, not the happy one.
6. **`Failed to refresh credentials` is usually a missing env var, not a broken
   login.** `credentials.json` holds an upstream `auth.shorebird.dev` token that
   expired 2026-07-26. The self-host path is `SHOREBIRD_TOKEN=<sb_api_…>`, which
   `code_push_server/tool/e2e_device.sh` already defaults from `API_KEY`.
7. **The Dart patch series order is now load-bearing.** `0008` is the first to
   touch a file another patch touches (`0005`, `precompiler.cc`). An edit landing
   next to `0005`'s hunk context makes `0005` report `[CONFLICT]` though nothing is
   wrong with it. Re-run `dart_patches.sh --verify` at the start of every sitting
   and *before* any iOS ninja — a green verify from a previous day says nothing
   about a shared, untracked tree.
