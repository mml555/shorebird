The marker is emitted by gen_snapshot from the compiler's own parsed
FLAG_patchable_static_calls, written as an ELF note beside the build-id
note. Not command-line text, not a build transcript, not Dart source, not
a behavioural patch test -- each of those records something other than
what the compiler did.

  .note.shorebird.capabilities   sh_type SHT_NOTE
  owner    Shorebird             note type 1
  payload  schema_version=1;patchable_static_calls=true|false

IDENTITY IS THE WHOLE HEADER. The reader parses the section table and
checks sh_type, owner, note type, and that exactly ONE such section
exists. A section name is not a signature, and a scan for the payload
text would match a Dart string literal a patch author controls.

PRODUCER PROVENANCE is banked in instrumentation/ -- base tree, the exact
source delta, and both gen_snapshot hashes -- so the causal claim can be
rebuilt rather than believed.
