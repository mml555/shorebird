SM1-G5 item 2 — A GENUINELY INLINED TARGET BODY, proved from machine code
date : 2026-09-08T01:00:34Z

WHY THE EARLIER ARM DID NOT COUNT. It named Base.work, which carries
vm:never-inline; only the HELPER was prefer-inline. That arrangement cannot
show a patched target BODY being copied into a caller and going stale, so
it was withdrawn rather than reinterpreted.

THE TARGET HERE has no never-inline pragma and is small:

    @pragma('vm:prefer-inline')
    int smallTarget() => DateTime.now().millisecondsSinceEpoch >= 0 ? 41 : 0;

    @pragma('vm:never-inline')          // keeps its own symbol to disassemble
    int callsSmall() => smallTarget() + 1;

A PRAGMA IS A REQUEST, NOT EVIDENCE. What follows is read out of the
shipped app.aot with llvm-objdump.

  inlined. There is no call to smallTarget here.

############ 2. nothing in the release calls smallTarget ############
  no 'bl <smallTarget>' anywhere in the artifact

############ 4. the observed result ############
  before alpha=OLD-a beta=OLD-b virtual=OLD-w direct=OLD-w inlined=OLD-w other=OTHER-w small=41 callsSmall=42
  APPLY ok: 1 target(s)
  after  alpha=OLD-a beta=OLD-b virtual=OLD-w direct=OLD-w inlined=OLD-w other=OTHER-w small=41 callsSmall=42

############ WHAT THIS ESTABLISHES ############
  smallTarget was patched 41 -> 141. The container verified the release,
  attached the replacement and reported APPLY ok. Both observers still read
  the old values: small=41, callsSmall=42.

  The patch replaced a function THAT NOTHING CALLS. Every call site holds a
  stale inlined copy of the old body, and the replacement is unreachable.
  This is proved from the machine code, not inferred from a pragma:
    * callsSmall and _state contain the target's own arithmetic;
    * no 'bl <smallTarget>' exists anywhere in the artifact;
    * the standalone symbol is present, so the patch had something to bind.

  It fails OPEN, like the two retention classes SM1-G4 measured and like a
  release built without --patchable_static_calls: success reported, nothing
  done.
