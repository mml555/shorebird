WHY THIS REFUSAL IS ATTRIBUTABLE TO THE STREAMS
-----------------------------------------------
In arm A no `--json` was passed and every CI-detection variable was unset (the
preflight asserts this and was observed refusing when they are set — see the
guard sweep). So of the four ways a run can be non-interactive, exactly two
were true, and both are stream tests:

  isInteractive       false because stdout is not a terminal
                      (interactive_mode.dart:18-22)
  canAcceptUserInput  false because stdin.hasTerminal is false
                      (shorebird_env.dart:292-293)

`_failIfNonInteractive` (shorebird_logger.dart:135-141) therefore threw, and
shorebird_cli_command_runner.dart:297-315 converted it — the human-readable
branch at :305-313 in arm A, the JsonErrorCode branch at :298-304 in arm B —
returning ExitCode.usage (64) at :315.

Arm B is the one that validates arm 2's literal grep token: the string
`interactive_prompt_required` comes from json_output.dart:54.
