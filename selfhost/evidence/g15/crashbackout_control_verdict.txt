WHERE THE SEAM ACTUALLY IS, LOCATED IN SOURCE
----------------------------------------------
third_party/tonic/dart_message_handler.cc, OnHandleMessage — one message-loop
turn:

    result = Dart_HandleMessage();          // line 115: THIS is where main runs
    error  = CheckAndHandleError(result);
    ...
    if (error) { UnhandledError(result); }  // line 133: POSITIVE failure signal

The first normal turn IS main(). An unhandled throw makes Dart_HandleMessage
return an error handle, and UnhandledError fires before the isolate is shut down
(it calls Dart_ShutdownIsolate itself, only for fatal errors, AFTER recording).

That yields both signals the gate needs at ONE place, one turn after Run:
  * FAILURE, positively reported, not inferred from silence
  * SUCCESS, at the first turn that completes with error == false
