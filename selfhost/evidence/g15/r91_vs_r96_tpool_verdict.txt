WHAT "ABSENT" DOES AND DOES NOT ESTABLISH
-------------------------------------------
ABSENT means: the `Function` object the patch attached to does not appear, by
pointer identity, in any of the global object pool's tagged entries.

It is worth naming a second reading, because the comparison does not depend on
which is true and an unstated alternative tends to get quietly assumed away:

* (a) no call site reaches the target through the global pool — the inlining
  reading; or
* (b) call sites reach it through a different object identity than the one
  `ResolvePatchTarget` returns.

**The comparison is unaffected either way**: whatever ABSENT means, both the
working and the failing release exhibit it, so it does not distinguish them. That
is the finding, and it holds under both readings.
