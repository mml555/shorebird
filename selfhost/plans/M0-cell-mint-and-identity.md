## Why this is the piece it is

A mint is a session boundary because every gate downstream is uninterpretable until the toolchain has a name — **not** because the build is long. Bundling identity into a gate is what made earlier device runs unattributable. This file is therefore two things at once: **the recipe for the NEXT mint** (steps 1-7, with `c0619d13`'s four promoted preconditions folded in as numbered checks) and **the closed record of THIS one** (the identity table below).

It deliberately does **not** include: cutting a release (`R6`/`R8`), bumping the fixture's version, installing anything on `R1`, building `G15`'s two-engine harness, or constructing `G3.7`'s live-path target. Those are the four blocked gates' own work orders. It also does not decide any gate's verdict.
